# example-tests

House example tests to guide AI.

## Prerequisites

- **Node.js 22 LTS** (recommended). Use [nvm](https://github.com/nvm-sh/nvm) to install:
  ```bash
  nvm install   # reads .nvmrc
  nvm use        # activates Node.js 22
  ```
- **npm** (bundled with Node.js)

## Project Structure

- `contract-tests/` — Contract testing examples
- `ui-component-tests/` — React UI component testing guide (Jest + React Testing Library)
- `unit-tests/` — Unit testing examples
